2026-10-05

핵심 재설계
1. 미래의 나를 일회성 시뮬레이터가 아닌 영구 TARGET BUILD로 저장.
2. 홈 최상단 흐름: NOW → TARGET BUILD → 다음 현실 성취.
3. 오늘 퀘스트를 CORE 5 강제형에서 ONE MOVE A DAY로 단순화.
   - 자격증 목표가 있으면 “실기 공부 2시간”처럼 시간 중심으로 기록.
   - 문제 수/암기 개수 강제 입력 제거.
4. 경력은 출근 체크가 아니라 입사일 기반으로 자동 증가.
5. 미래 점수 계산 경로 수정/회귀 테스트.
   - 테스트: 전기산업기사 + 0.3년 48 → 전기기사+전기공사+소방전기 + 3.3년 73 (+25)
6. 실기 목표가 활성화되면 해당 자격의 필기 통과 상태를 미래 빌드 진행률에 부분 반영.
7. LV.10/20/30/40/50 현실 성장 마일스톤 로드 추가.
8. 웹 배포 루트 index.html 추가. GitHub Pages에 폴더 전체 배포 가능.
9. 가독성 패스: 핵심 본문/라벨 폰트 확대.
10. 4.1 JOB MARKET MAP 및 4.0.1 경력 안전장치 유지.

중요한 현재 한계
- 계정/비밀번호/데이터는 브라우저 localStorage 기반. 실제 서버 인증이 아님.
- PC/휴대폰 자동 동기화 없음.
- 실제 다기기 웹서비스 단계에서는 백엔드 인증/DB가 필요.
- 채용 AI 수치는 합격확률이 아니며, 근거가 약한 트랙은 휴리스틱이 남아 있음.
