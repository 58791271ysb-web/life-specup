인생 스펙업 4.0 — LIFE / CAREER OS REBUILD
2026-10-05

이번 버전은 3.x 패치가 아니라 데이터 구조 재정비 버전입니다.

핵심
- 경력 저장형식을 job/current 한 종류로 통일
- 가입 재직경력 → 내 정보 → Career AI가 동일 Career History 사용
- 기존 jobTitle/isCurrent 데이터 자동 정규화
- 현재 재직 1개 제한
- 중복 기간/현재경력 차단
- 미래 입사일/종료일 역전 차단
- 재직기간은 오늘 날짜까지 자동 증가
- 날짜가 없는 과거 경력은 년/개월 직접 입력 가능
- 데이터 상태 자체 점검 표시
- 보유 입력 자격 + 인증 자격을 Career AI가 통합 조회
- 미래 프로필: 경력 직접 입력, 전체 자격 DB 검색, 현재/미래 비교
- Career AI: 실제 트랙 우선, 하드게이트, 신뢰범위, 점수 근거
- 공공 트랙은 NCS/전공 미입력 시 자격만으로 경쟁권 판정하지 않음
- 합격자 실제 데이터가 없으면 합격확률/합격자 평균을 생성하지 않음
- 계정별 Career Profile/Schema 키까지 분리

자동검증
- 모든 JS 구문 검사
- 모든 HTML 로컬 참조 검사
- HTML 중복 ID 검사
- legacy 경력 migration
- 현재경력 중복 차단
- 과거경력 추가
- 미래일 차단
- 직접입력 경력
- 저장/재정규화 roundtrip
