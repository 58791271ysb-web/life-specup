인생 스펙업 5.1 — WEB RELEASE CANDIDATE

핵심 수정
- 퀘스트 목표 시작 로직 전면 교체: HTML id 자동 전역변수 의존 제거
- '이 목표 시작하기'를 명시적 DOM + addEventListener 구조로 변경
- 목표 생성 즉시 오늘의 핵심 퀘스트 연결
- 커리어 화면의 '목표로' 진입 시 추천 자격증 자동 선택
- 실기 목표 시작 시 TARGET BUILD에 필기 합격 단계 진행상태 연결
- 하루 공부 완료 XP 중복 지급 방지 및 같은 날 학습일 중복 증가 방지
- 새로고침 후 장기목표/오늘 완료/XP 유지
- 홈 오늘 완료 상태를 실제 simple quest 데이터 기준으로 표시
- 홈 최근 7일 달성률을 구형 CORE 5 정산 데이터가 아닌 실제 일일 핵심퀘스트 기준으로 변경
- TARGET 화면에 기존 보유 자격 + 미래 목표 자격을 합쳐 '미래의 나' 전체 자격 구성 표시
- 레벨 마일스톤은 핵심 기능 잠금이 아닌 기록/휘장 중심으로 문구 수정
- GitHub Pages용 루트 index.html 유지

데이터 원칙
- 관련경력은 실제 경력 날짜에서 계산
- 공부 퀘스트 완료가 경력 일수를 직접 증가시키지 않음
- 실기 공부 완료가 자격증 취득으로 자동 처리되지 않음
- 필기합격/실기준비는 미래빌드 진행상태일 뿐 보유 자격으로 취급하지 않음
- 현재 스펙과 미래 시뮬레이션 상태 분리

주의
- 현재 로그인/데이터 저장은 브라우저 localStorage 기반입니다.
- GitHub Pages에 배포해도 기기 간 계정/데이터 동기화는 되지 않습니다.
- 실제 다기기 로그인은 향후 백엔드/DB가 필요합니다.
